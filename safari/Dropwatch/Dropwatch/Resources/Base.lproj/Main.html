Track prices in Safari

Turn on the Dropwatch extension, then Track on Amazon or Flipkart product photos.

Dropwatch is on. In Safari, click the toolbar icon, paste your token from Settings, and allow access on Amazon.

Dropwatch is off. Enable it in Safari Settings → Extensions, and set permissions to Allow on websites.

  1. Safari → Settings → Advanced → Show features for web developers
  2. Develop → Allow Unsigned Extensions
  3. Settings → Extensions → Dropwatch on, permissions Allow
  4. Toolbar icon → paste token → Connect
  5. Product page → Track with Dropwatch on the photo
